## Spring starts here 책 학습 계획

### **1주차: 스프링의 핵심 기초 다지기 튼튼하게!**

이 주에는 스프링 프레임워크가 어떻게 동작하는지에 대한 가장 근본적인 원리를 배우게 될 거예요. 여기가 가장 중요하니, 꼼꼼하게 이해하고 넘어가는 게 좋아요.

- **1일차: 스프링과 친해지기 (Chapter 1)**
    - **학습 목표:** 프레임워크가 왜 필요한지, 스프링이 어떤 생태계를 가지고 있는지 가볍게 이해합니다.
    - **팁:** 앞으로 배울 내용에 대한 큰 그림을 그리는 시간이에요. 편안한 마음으로 읽어보세요.
- **2일차: 스프링의 심장, 스프링 컨텍스트와 빈(Bean) 🌱 (Chapter 2)**
    - **학습 목표:** 스프링이 객체를 어떻게 관리하는지(IoC 컨테이너), 그리고 그 관리 대상인 '빈(Bean)'을 어떻게 등록하는지 배웁니다.
    - **팁:** 스프링의 가장 핵심적인 개념이 시작되는 곳이에요. `@Bean`, `@Component` 어노테이션의 차이를 생각해보며 코드를 작성해보세요.
- **3일차: 빈(Bean)들 연결하기 (Chapter 3)**
    - **학습 목표:** 스프링 컨텍스트에 등록된 빈들을 서로 연결(의존성 주입, DI)하는 방법을 익힙니다.
    - **팁:** `@Autowired`가 어떻게 동작하는지, 생성자 주입 방식이 왜 권장되는지 생각해보면 좋아요. 순환 참조 문제도 한번쯤 직접 겪어보면 기억에 오래 남을 거예요.
- **4일차: 더 유연한 설계, 추상화 활용하기 (Chapter 4)**
    - **학습 목표:** 인터페이스를 사용해서 컴포넌트 간의 결합도를 낮추는 방법을 배웁니다.
    - **팁:** 좋은 설계를 위해 왜 인터페이스(추상화)가 중요한지 이해하는 시간입니다. 실제 현업에서 코드를 작성할 때 정말 중요한 부분이에요.
- **5일차: 빈(Bean)의 생명주기 이해하기 (Chapter 5)**
    - **학습 목표:** 빈이 언제 생성되고 소멸되는지(스코프)를 배웁니다. 싱글톤과 프로토타입의 차이를 명확히 알아두세요.
    - **팁:** 싱글톤 스코프가 왜 기본값인지, 상태를 가지는 빈을 어떻게 다뤄야 할지 고민해보세요.
- **6일차: 마법 같은 기능, AOP 맛보기 (Chapter 6)**
    - **학습 목표:** 핵심 비즈니스 로직과 부가 기능을 분리하는 관점 지향 프로그래밍(AOP)의 개념을 이해하고 간단한 예제를 만들어봅니다.
    - **팁:** AOP는 처음엔 조금 낯설 수 있어요. '어떤 코드 흐름에 내가 원하는 기능을 끼워 넣는다'는 느낌으로 접근해보세요.
- **7일차: 1주차 복습 및 휴식 🧘**
    - **학습 목표:** 1주 동안 배운 스프링의 핵심 개념(IoC, DI, AOP)을 다시 한번 정리합니다.
    - **팁:** 막혔던 부분이 있다면 다시 한번 코드를 실행해보거나, 개념을 정리하며 자신만의 노트를 만들어보는 걸 추천해요!

### **2주차: 실전! 웹 애플리케이션 기능 구현하기**

이제 탄탄한 기초 위에 실제 웹 애플리케이션을 만드는 데 필요한 기술들을 하나씩 쌓아 올릴 차례예요!

- **8일차: Spring Boot와 MVC 첫 만남 🕸️ (Chapter 7)**
    - **학습 목표:** Spring Boot가 얼마나 편리한지 경험하고, 웹 요청을 처리하는 MVC 아키텍처의 흐름을 이해합니다.
    - **팁:** 이 책의 가장 신나는 부분 중 하나일 거예요! 몇 줄의 코드만으로 웹 서버가 실행되는 마법을 경험해보세요.
- **9일차: 동적인 웹 페이지 만들기 (Chapter 8)**
    - **학습 목표:** 서버의 데이터를 웹 페이지에 동적으로 보여주는 방법과, 클라이언트의 데이터를 서버로 전송하는 방법을 배웁니다.
    - **팁:** `Model` 객체, `@RequestParam`, `@PathVariable`의 쓰임새와 차이점을 비교하며 학습하세요.
- **10일차: 웹 스코프와 REST API의 시작 ↔️ (Chapter 9, 10)**
    - **학습 목표:** 로그인 상태 유지 등에 사용되는 웹 스코프를 이해하고, 현대적인 애플리케이션의 표준인 REST API를 구현하는 방법을 배웁니다.
    - **팁:** `@RestController`와 `@Controller`의 차이점을 이해하는 것이 중요해요.
- **11일차: 외부 API 호출하기 (Chapter 11)**
    - **학습 목표:** 내 애플리케이션이 다른 서버의 REST API를 호출(소비)하는 세 가지 방법을 배웁니다.
    - **팁:** `RestTemplate`, `WebClient`, `OpenFeign`의 장단점을 비교해보세요. 특히 OpenFeign의 편리함에 놀라게 될 거예요!
- **12일차: 데이터베이스 연동의 첫걸음 💾 (Chapter 12)**
    - **학습 목표:** `DataSource`가 무엇인지 이해하고, `JdbcTemplate`을 사용해 데이터베이스에 데이터를 저장하고 조회하는 방법을 익힙니다.
    - **팁:** 데이터베이스 설정이 조금 번거로울 수 있지만, 한번 성공하고 나면 자신감이 붙을 거예요!
- **13일차: 데이터 무결성을 위한 트랜잭션 (Chapter 13, 14)**
    - **학습 목표:** 중요한 데이터 작업을 안전하게 처리하는 트랜잭션의 개념을 배우고, 훨씬 더 편리하게 데이터베이스를 다루는 Spring Data JDBC를 사용해봅니다.
    - **팁:** `@Transactional` 어노테이션 하나로 복잡한 트랜잭션 처리가 해결되는 것을 보며 AOP의 강력함을 다시 한번 느껴보세요. Spring Data의 마법 같은 쿼리 생성도 경험해보세요!
- **14일차: 나의 코드를 믿는 방법, 테스트 ✅ (Chapter 15) 및 최종 복습**
    - **학습 목표:** 내가 만든 코드가 잘 동작하는지 검증하는 단위 테스트와 통합 테스트 방법을 배웁니다.
    - **팁:** 좋은 개발자는 테스트 코드 작성의 중요성을 알고 있답니다. 2주간의 학습 여정을 마무리하며 전체적인 흐름을 다시 한번 복습해보세요.
